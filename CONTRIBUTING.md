# Contributing

Thanks for helping improve PetalDex. Use GitHub issues for questions and bug reports, and pull requests for proposed changes.

## Report a problem

Include the repository commit, OS, Python and PyTorch versions, GPU and CUDA driver, exact command, and the relevant traceback. For data problems, include the subset, episode, array shapes, and a small shareable example where possible. Remove credentials and private recording content from logs.

## Propose a change

1. Fork the repository and create a branch for one focused change.
2. Describe the problem, the resulting behavior, and any compatibility changes.
3. State what you checked and what you could not run. For policy changes, distinguish offline prediction, training, and real-robot evaluation.
4. Preserve third-party copyright and license notices and acknowledge new dependencies.

Keep large datasets, checkpoints, generated predictions, and local environment files out of Git. The project currently has no automated test suite; do not describe static review as a successful reproduction.
