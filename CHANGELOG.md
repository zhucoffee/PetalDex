# Changelog

## 0.1.0 — 2026-11-01

Initial PetalDex release.

- HDF5 and ROS 2 MCAP converters for bimanual flower-arrangement demonstrations.
- Policy, dataset loader, and training configurations in the `petal` Python package.
- Single-GPU and multi-GPU training with checkpointing, EMA, and gradient accumulation.
- Offline action prediction from recorded observations.
- Installation, data-format, evaluation, and contribution guides.
- MIT-licensed code with retained Diffusion Policy notices; dataset terms are provided separately.
